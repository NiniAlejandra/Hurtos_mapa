# Sistema de Análisis de Hurtos - Alumbrado Público

Aplicación web desarrollada con Dash para visualizar y analizar datos de hurtos en el sistema de alumbrado público de ESIP SAS ESP.

## Características

- Visualización geográfica de hurtos con mapas interactivos
- Filtros por año y tipo de visualización
- Gráficos de distribución temporal (mensual y anual)
- Estadísticas en tiempo real
- Interfaz responsiva y moderna

## Tecnologías

- Python 3.11
- Dash (Framework web)
- Plotly (Visualizaciones)
- Pandas (Procesamiento de datos)
- Gunicorn (Servidor WSGI)

## Instalación Local

1. Clonar el repositorio
2. Instalar dependencias: `pip install -r requirements.txt`
3. Ejecutar: `python app.py`

## Despliegue

La aplicación está configurada para despliegue automático en Render.
